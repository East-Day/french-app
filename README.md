French Learning Web App (Atelier)

An interactive web application designed as a personal study assistant to master French grammar and vocabulary. Built using a Vibe Coding workflow.

 ✨ Key Features
Verb Conjugations : Practice present indicative and other tense transformations
Noun Gender & Forms : Interactive drills for determining masculine/feminine forms and pluralization rules
Atelier Interface: A sleek, distraction-free immersion environment optimized for high-efficiency self-testing
